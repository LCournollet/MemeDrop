MemeDrop

Les memes de ton Discord, en overlay sur l'écran de tes potes.

Télécharger pour Windows

Installation

  1. Lance MemeDrop-Setup.exe.
  2. Si Windows affiche « Windows a protégé votre ordinateur » : Informations complémentaires puis Exécuter quand même (l'app n'est pas signée).
  3. Entre le code de salon qu'on t'a donné. L'app tourne ensuite dans la barre des tâches et se met à jour toute seule.
